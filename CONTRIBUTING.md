# Участие в ErrLens

Используйте Python 3.11+ и локальное виртуальное окружение. Инструкция установки
находится в README. Перед предложением изменений запустите:

```console
python -m pytest
python -m mypy
python -m build
```

Описывайте проблему, область изменений и выполненные проверки. Добавляйте
регрессионные тесты для исправляемого поведения. Не заявляйте проверку ОС,
на которой тесты не выполнялись. Не включайте секреты или личные данные в fixtures.

Сохраняйте независимость анализаторов от CLI, переводов и ввода-вывода.
Не выполняйте рекомендации автоматически. Новые переводы должны иметь те же
ключи и именованные параметры, что и русская локаль. Сторонние плагины и сетевые
запросы не должны загружаться или запускаться неявно.

Текущий CLI включает объяснения, shell-интеграции и явный PTY/ConPTY-режим.
Команды рекомендаций должны оставаться display-only argv из доверенных правил;
не подставляйте произвольные имена из traceback в shell-строки. Проверяйте plain
text, узкие терминалы и буквальный вывод разметки/управляющих символов.
Следующие возможности реализуются
отдельно. Изменения распространяются на условиях MIT License проекта.
